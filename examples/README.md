# Examples

This directory contains example code and configuration for integrating with the Chivox Speech Evaluation MCP Service.

## Examples Overview

| Directory | Description | Language |
|-----------|-------------|----------|
| [customer-server/](customer-server/) | Secure API Key proxy server with web UI | Python (Flask) |
| [claude-desktop/](claude-desktop/) | Claude Desktop configuration | JSON config |
| [cursor/](cursor/) | Cursor IDE configuration | JSON config |
| [quick-test/](quick-test/) | Minimal test scripts | Python, Node.js, curl |

## Which example should I use?

- **Just want to try it?** Start with [claude-desktop/](claude-desktop/) or [cursor/](cursor/)
- **Building a web app?** Use [customer-server/](customer-server/) as a starting point
- **Testing the API programmatically?** Check [quick-test/](quick-test/)
